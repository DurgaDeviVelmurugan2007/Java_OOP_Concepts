## ▶️ How to Run

Make sure **Java JDK** is installed on your system.

### 1. Clone the repository

```bash
git clone https://github.com/your-username/Java-OOP-Lab-Experiments.git
```

### 2. Navigate to an experiment

```bash
cd Java-OOP-Lab-Experiments/Experiment-01-Classes-Objects
```

### 3. Compile the program

```bash
javac Main.java
```

### 4. Run the program

```bash
java Main
```

For experiments involving packages or multiple Java files, compile and run according to the structure provided in that experiment's `README.md`.
